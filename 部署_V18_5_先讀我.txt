Alpha Radar V18.5｜部署先讀我

【下載選擇】
- V18.5 完整包：適用不確定目前 GitHub 檔案是否完整、或想最穩妥覆蓋更新。
- V18.5 替換包：已完整安裝 V18.4 者，可將壓縮檔內同名檔案直接上傳 GitHub 根目錄覆蓋。

【部署】
1. 壓縮檔不用原封不動上傳 GitHub。完整包打開後，請將 alpha_radar_v18_5 資料夾內「所有內容」放在 GitHub 專案根目錄。
2. 保留 app.py 作為 Streamlit 入口，Secrets 沿用原設定。
3. 既有行情／公司資料庫可繼續使用，不要為了同步狀態而隨意「清除全部歷史快取」。
4. 重新部署後，執行一次「背景更新日線模型」，取得最新的官方上市、上櫃日期來源欄位。
5. 使用順序：今天看「今日決策」→ 要比較股票看「選股與買點」→ 查日期與美股新聞看「市場與資料」→ 有指定股票看「個股診斷」。

【錯誤處理】
- 已同步：上市、上櫃與模型日一致。
- 安全回退：來源不同步，全部股票以同一較早交易日研究；不是兩種日期混用。
- 來源未核對：官方公告或擷取未成功，研究名單可參考、立即買賣判定暫停。
- 資料異常：零檔、混用交易日、快照回存失敗，保留上一份已完成結果。

【限制】
模型排序仍為 V18.4 原策略，V18.5 是操作／日期可信度修正。工程離線 QA 通過，實際行情 API、Streamlit Cloud 端到端及實盤績效仍須部署後驗證。
